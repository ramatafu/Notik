# Notik — минималистичный блокнотик

**Notik** — это простое и приватное приложение для заметок на Android.

---

## ✨ Особенности

- 📝 Заметки с форматированием (жирный, курсив, моноширинный)
- ✅ Чек-листы
- 🎂 Дни рождения с напоминаниями
- 🔒 Защита заметок паролем
- 🌙 Светлая и тёмная тема
- 🔒 Полный офлайн — без доступа в интернет
- 📦 Резервное копирование и восстановление из ZIP
- 🌐 Поддержка русского и английского языков
- 📱 Виджет на главный экран
- 📤 Экспорт в TXT, JSON, HTML, PDF

## 🛠️ Как собрать

1. Открой папку проекта в **Android Studio** (Koala / Ladybug или новее).
2. Дождись синхронизации Gradle.
3. Запусти на эмуляторе или реальном устройстве (minSdk 24).
