# Notik

Минималистичное приложение для заметок с акцентом на приватность.

## Особенности
- 📝 Заметки с форматированием (жирный, курсив, моноширинный)
- ✅ Чек-листы
- 🎂 Дни рождения с напоминаниями
- 🌙 Светлая и тёмная тема
- 🔒 Полный офлайн — никакого доступа в интернет
- 📦 Резервное копирование и восстановление из ZIP
- 🌐 Поддержка русского и английского языков
- 📱 Виджет на главный экран
- 📤 Экспорт в TXT, JSON, HTML, PDF
