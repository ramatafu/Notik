# NoteFlow

Приложение для заметок на Kotlin + Jetpack Compose, написанное с нуля.
Идейно вдохновлено [Notally](https://github.com/OmGodse/Notally), но не
содержит его кода — своя архитектура, своя реализация.

## Функционал

- Текстовые заметки и чек-листы
- Форматирование: **жирный**, *курсив*, `моно`, ~~зачёркнутый~~
- Автоопределение ссылок, email и телефонов
- Изображения в заметках
- Цвет, пин, лейблы, поиск, архив, корзина (автоочистка через 7 дней)
- Напоминания (точные, через AlarmManager) с уведомлениями, переживают перезагрузку
- Виджет на главный экран с закреплёнными заметками
- Экспорт заметки: TXT / JSON / HTML / PDF
- Полный бэкап и восстановление всех заметок одним zip-файлом

## Как собрать

1. Открыть папку `NoteFlow` в Android Studio (Koala/Ladybug или новее).
2. Android Studio сама сгенерирует `gradle-wrapper.jar` при первой
   синхронизации (в этом окружении не было доступа в сеть, поэтому сам
   jar-файл wrapper'а не включён — `gradle-wrapper.properties` уже настроен
   на Gradle 8.7).
3. Дождаться Gradle Sync, запустить на эмуляторе/устройстве (minSdk 24).

## Известные ограничения текущей версии

Это рабочий, спроектированный "по-настоящему" каркас со всей архитектурой
и логикой, но он не компилировался и не тестировался в реальном Android
Studio (в этой среде нет Android SDK/эмулятора). Перед первым запуском
вероятно потребуется:

- добавить недостающие импорты, если что-то не подтянулось при Gradle Sync;
- заменить иконки-заглушки (`ic_notification`, `ic_launcher_foreground`) на
  свои;
- на Android 12+ разрешение `SCHEDULE_EXACT_ALARM` может потребовать
  дополнительного экрана с просьбой предоставить точные будильники в
  настройках (`Settings.ACTION_REQUEST_SCHEDULE_EXACT_ALARM`) — сейчас код
  предполагает, что разрешение уже выдано.
